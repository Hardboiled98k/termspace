缩到全景时终端退化成色块 —— 边框颜色就是 agent 的状态

它解决什么

十几个 agent 同时跑，不用一个个点进去看

蓝色在跑、橙色在等你、红色出错。状态来自 Claude Code / Codex 的 hook 事件 —— 是真状态，不是从输出里猜的。

同一台机器，多个订阅号并行

凭证是画布上的节点，连线到终端就是"这个终端用这个号"。每个账号一个隔离登录空间，右上角实时显示各自还剩多少额度。

agent 之间能互相派活

把活派给画布上另一个 agent，跨机器也行 —— 走你已有的 ssh，不开任何端口。每次派活都留痕，回来能看清哪些结果可信。

关掉再打开，还在原处

会话由 tmux 托着，重启 app 不会杀掉正在跑的活。布局、滚动历史、上下文都留着。

派活长这样

# 把活派给画布上另一个终端里的 agent
tb ask t-7k3 "把 auth 那块的测试补齐"

# 跨机器同理，走你已有的 ssh 别名
tb ask mac-mini:t2 "跑一遍完整回归"

# 让 agent 查生产库，但拿不到连接串
tb db prod "select count(*) from orders where created_at > now() - interval '1 day'"

最后一条是刻意设计的：连接串只在主进程里流转，一个字节都不进终端。 agent 用得到这个数据库，但看不到密码。

装之前

需要 macOS 12 或更新，Apple Silicon 与 Intel 都有包。安装包已通过 Apple 公证，正常不会被 Gatekeeper 拦。

首次启动会问你要不要写入 Claude Code / Codex 的 hook 配置 —— 那是状态灯的数据来源。 你可以拒绝，其余功能照常，只是节点边框不会跟着 agent 状态变。

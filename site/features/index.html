功能

八件事，每件都能在界面上指出来

每一条都能在应用里找到对应的界面。做到一半的会写「部分」， 没做的单独列在最后一节，不混在里面充数。

01 · 画布

终端是节点，不是标签页

拖到哪就在哪。相关的放一起，不相关的推远。空间本身就是一种组织方式 —— 这是 tab 栏给不了的。

缩到全景不读字

缩放低于阈值时终端退化成色块，只留标题和状态点。 几十个节点一屏看完，靠颜色分布做判断。

成组

框选即成组，整组拖动、折叠、群发命令。组标题显示成员状态聚合， 按最紧急的那个显示。

浏览器节点

画布上也能放网页，agent 可以驱动它。 每个浏览器节点一个独立的登录空间，互不串。

02 · 状态

边框颜色就是 agent 在干什么

状态来自 hook 事件，不是从终端输出里正则匹配的。 agent 说它在等你，节点才变橙。

状态视觉什么时候
运行中 蓝边框 + 呼吸 glowagent 正在工作
需要你 橙边框 + 静态 glow等你审批工具调用，或等你回话
空闲 无 glowshell 在，没有 agent 在跑
出错 红状态点 + 内容灰化进程退出异常

装不装 hook 由你决定。 首次启动会问要不要写入 Claude Code / Codex 的 hook 配置。 拒绝的话其余功能照常，只是边框不再跟着 agent 状态变。 目前只有这两家有真状态 —— 其他 CLI 的 hook 形态不同，还没接。

03 · 账号

同一条命令，两个终端登两个号

靠给每个终端注入不同的配置目录做到 —— 不是靠反复登出登入。

凭证是画布上的节点

从凭证节点拉一根线到终端，就是「这个终端用这个号」。 拉线会重启该终端的会话，所以拉之前会问一次。

连线不等于自动登录

隔离目录是空的，第一次仍要在那个终端里跑一次登录命令。 节点上会显示登录态 —— 查不到就如实说查不到，不猜。

值加密存，界面只显示键名

凭证内容用系统钥匙串加密后落盘。界面层拿得到有哪些环境变量， 拿不到它们的值 —— 已保存的明文永不回传。

能显式删掉一个变量

你 shell 里 export 的 API key 会被应用继承，让订阅号白开还产生账单。 所以每个变量有三种操作：保留、替换、删除。

04 · 额度

还剩多少，一眼看到

Claude、Codex、Copilot 三家实时查，五分钟一轮。 一个账号拉一次，广播给所有用它的节点 —— 额度是账号级的。

窗口语义从数据来

五小时窗还是周窗，由接口返回的窗口时长决定，不按返回顺序猜。 没有的窗口就不显示，不虚构一行。

「查不到」和「用了 0%」是两回事

还有第三种：「未登录」。这三个必须分开显示 —— 未登录你能自己修，查不到只能等。

按量计费会明说

某个账号实际在按 token 计费时，卡片上直说， 不让它伪装成一个「还剩很多」的订阅号。

不是所有 provider 都能查 —— 有的没有公开的用量接口。查不了的会列出来并说明原因， 而不是显示一个空的进度条。

05 · 派活

agent 指挥 agent

这是整个产品里最危险的一段 —— 派活就是替你敲回车。所以闸门比别处都密。

t-4a2 — zsh
# 同一块画布上
tb ask t-7k3 "把 auth 那块的测试补齐"

# 跨机器，走你已有的 ssh 别名，不开任何新端口
tb ask mac-mini:t2 "跑一遍完整回归"
  • 只往活着的 agent 会话里派 状态判定 fail-closed 目标终端里如果不是一个正在运行的 agent，而是一个光秃秃的 shell，派活会被拒绝 —— 否则任务正文就成了直接执行的 shell 命令。
  • 控制字符会被摘掉 sanitizeTask 任务正文里的退出键（Ctrl-C / Ctrl-D 之类）会让 agent 退出， 剩下的字节就落到重新拿回终端的 shell 手里。这些字符在确认弹窗里根本不可见。
  • 断线不自动重试 十分钟幂等表 注入不可撤回，重试就是往对面 agent 里注两遍。 人工重发也挡得住 —— 同一个任务十分钟内只生效一次，直接返回上次的结果。
  • 完成判定认会话，不认时间 transcript 路径比对 目标中途退出重开的话，新会话产生的回答不会被当成本轮结果返回。

06 · 隔离

一个组一棵 git worktree

并行 agent 打架的根子是共享工作目录。与其在提示词里求它们别乱动， 不如物理隔离 —— 每组一个独立分支、独立目录。

组头显示分支和脏文件数

不是 git 仓库的目录上，这个功能完全不出现 —— 不做无关的噪音。

脏的时候拒绝删除

git 本身就会拒绝，那个拒绝是特性不是障碍。 把改动数量摆给你看，你自己决定，绝不替你加 --force。

07 · 手机

出门也能看一眼、批一下

只绑回环地址或 Tailscale 网卡，永远不绑 0.0.0.0。 手机上是同一块画布的地图视图。

写操作只有两类

往终端敲字、批准工具调用。各自独立开关， 没有新建和删除节点的入口 —— 手机丢了损失更小。

开关关掉立刻断

不是「下次重启生效」。点关通常是在应急撤权，等重启就晚了。

审批内容脱敏后才出网

工具调用的完整参数不出主进程，只发够你做判断的部分。

08 · 续存

不怕关，也不怕更新

会话活过应用重启

底下是 tmux。退出应用不杀会话，重开接回原来那个。 布局和滚动历史一起留着。

更新永远等你点

后台检查、后台下载，装不装你说了算。 终端里跑着你的活，自动重启会把正在进行的对话掐掉。

没做

明确不在里面的东西

列出来是因为不列的话，你要装上之后才发现。

没有原因
MCP server 形态 派活和工具中枢现在走命令行 + 本地回环 HTTP，够用。跨 provider 统一的收益还没兑现
Claude / Codex 之外的真状态 其他 CLI 的 hook 形态不同。裸终端只能靠输出活跃度猜，那不算真状态
节点拆成独立系统窗口 多个渲染进程共享 pty 所有权太复杂，而且还没看到真实需求
手机端后台推送 目前是前台轮询，退到后台就不再收。真通知需要推送服务，本地服务器做不到
Windows / Linux 只有 macOS 版本。签名、钥匙串、tmux 这几条链路都是按 macOS 写的

装上试试

macOS 12 或更新，Apple 芯片和 Intel 都有包。
